# Student Performance Prediction System and Risk Analyzer

## Overview

This project is a Python-based system that analyzes student academic performance and predicts their performance using CAT marks and attendance.

## Features

- Student details management
- CAT 1, CAT 2 and TEE marks input
- Marks validation
- Total marks and percentage calculation
- Performance classification
- Performance prediction
- Academic risk analysis
- Personalized recommendations

## Technologies Used

- Python
- VS Code
- Git and GitHub

## Project Modules

- `main.py` - Main program
- `student.py` - Student details
- `marks.py` - Marks calculation
- `validation.py` - Input validation
- `performance.py` - Performance calculation and prediction
- `risk_analyzer.py` - Risk analysis
- `recommendation.py` - Recommendations
- `report.py` - Report generation

1. Install Python.
2. Open the project folder in VS Code.
