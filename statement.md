# Project Statement

## Problem Statement

Students may find it difficult to understand their academic performance and identify whether they are at academic risk.

This project provides a simple system to analyze student marks and attendance, predict performance, identify risk, and provide recommendations.

## Scope

The project focuses on analyzing student academic information using Python.

## Target Users

- Students
- Teachers
- Academic users

## High-Level Features

- Student information input
- Marks and attendance input
- Performance calculation
- Performance prediction
- Risk analysis
- Recommendations
